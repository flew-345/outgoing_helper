# 自有校园路线规划

前端使用本地 OSM 道路快照运行 Dijkstra，沿道路节点和有向边求最短距离。无需高德 Key，计算时不向第三方发送起终点。底图仍使用在线 Esri 瓦片；路网文件首次加载后可在本页继续计算。

## 数据与刷新

`public/data/campus-roads.json` 包含武汉大学及周边的 WGS84 道路、节点、门禁标记、数据时间和来源。范围为南界纬度 30.515、西界经度 114.337、北界纬度 30.560、东界经度 114.388；实际覆盖不能超出这个边界。

```powershell
python scripts/fetch-roads.py
# 可用其他公开实例；代理参数仅作用于这一条请求，不更改系统或手机设置
python scripts/fetch-roads.py --endpoint https://maps.mail.ru/osm/tools/overpass/api/interpreter --proxy http://127.0.0.1:7897
```

脚本仅在人工更新时调用 Overpass。网页不会为每条路线请求公共数据服务。数据 © OpenStreetMap contributors，按 [ODbL](https://www.openstreetmap.org/copyright) 使用和提供；打包时必须保留道路 JSON 和页面署名。接口和使用限制见 [Overpass 官方项目文档](https://wiki.openstreetmap.org/wiki/Overpass_API)。

预置地点采用 OSM 建筑中心或校门位置，来源 ID 写在 `Place.source`，不是建筑入口坐标。桂园宿舍取桂园一舍中心，工学部教学楼取工学部第二教学楼中心。总馆坐标本次未获得可靠来源，原演示的「总图书馆」预置项已替换为 OSM 明确标注的工学部图书馆。总馆或其他未收录地点可通过地图选点。

## 计算规则

- 步行与自行车分别筛选道路。排除施工、禁行、私有且未明确开放的道路及仅限特定用途或无法判断条件限制的道路；自行车排除台阶、未明确允许骑行的人行道，并遵守单行。门禁仅按 OSM 已有的通行、锁闭标记处理。
- 起终点投影到最近可用道路，最大接入距离 120 米。只连接同一条道路上的节点，不将交叉但没有共同节点的道路拼接。缺失、越界或不连通时不给出替代直线路线。
- 灰色虚线是地点至路网的接入段，入口和通行尚未验证。道路步骤展示道路名称和距离，不提供实时定位转向指令。
- 步行按 72 米/分，自行车按 200 米/分估算；自行车接入段按步速计。无坡度、天气、租车、临时施工或实时门禁信息，不用于电动车通行判断。
- 校巴方案使用校方路径和原始站次，寻找步行接入 → 一次乘车 → 步行离站。上车站序必须小于下车站序；重复站名保持独立站次，路径不能对上则不提供候选。只保留减少步行距离的候选，按接入步行与乘车距离排序。不处理多线换乘、运营可用性或校巴总耗时，不以未知候车时间参加「估算最快」比较。车辆和运营时间需在校巴页核实。

## 可扩展接入

`src/lib/road-router.ts` 提供图解析、最短路径和校巴组合。`src/lib/route-provider.ts` 定义 `RouteProvider` 扩展契约，今后可在服务端接入 [高德路线 API](https://lbs.amap.com/api/webservice/guide/api/direction)，将结果归一为 WGS84 的 `Route`；Key 不应放入浏览器。当前未接入高德服务端 API。

网页提供 [高德 URI 跳转](https://lbs.amap.com/api/uri-api/guide/travel/route) 作为可选独立规划入口，先将坐标转换为 GCJ-02；骑行跳转仅适用于移动端。跳转传递同一起终点，高德自行算路，不接收本地规划路径。校巴候选不跳转到通用公交，避免误认为高德包含校内校巴。
