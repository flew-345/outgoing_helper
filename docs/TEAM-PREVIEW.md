# 珞珈畅行 · 团队预览与交付

预览包用于查看界面、交互和基于随包路网的实际规划。默认校巴数据是采集快照，持续实时数据需独立启动采集器。

## Windows 免安装打开

1. 解压整个 ZIP 到普通文件夹，不要在压缩软件中启动。
2. 双击 `start-preview.cmd`，浏览器会打开预览。
3. 保持启动窗口运行，Ctrl+C 或关闭窗口停止服务。

适用于 Windows 10/11 x64，已包含 Node.js，不需另装项目依赖。默认地址 `http://127.0.0.1:4173`，占用时尝试后续端口，以窗口输出为准。仅本机可访问。

已有浏览器时可手动执行 `start-preview.cmd --no-open`，再访问窗口显示的地址。`screenshots/` 有桌面与手机截图，截图反映保存时的界面，不是当前车辆位置。

## 实际功能和数据边界

- 步行、自行车使用随包 OSM 真实路网，距离沿路计算，耗时按固定速度估算；接入入口尚未核实。不可达时不生成直线路线。
- 校巴组合使用站序和实际轨迹，仅支持一次乘车；候车和乘车总耗时未知，尚不判断当前是否运营。
- 四个校巴方向来自校方 H5 响应；默认快照车辆时间超过 30 秒标为过期。重复读取静态文件不会变成实时采集。
- Esri 底图与卫星影像需要联网；路网加载后可在当前页面计算，未提供完整离线安装能力。
- 公告为 2026-10-10 09:30 演示记录，不参与避障；问答是本地规则；没有租车平台库存和开锁能力。
- 校巴坐标系依据高德用法推断，未获上游声明；5 号线时刻表存在冲突，票价未核实，不提供分钟 ETA。

## 接入实时采集

在配套源码目录安装 Python 3.10+ 与 `scripts/transit/requirements.txt`，另开终端运行：

```powershell
python scripts/transit/collector.py --serve --no-persist
```

在预览网页“数据说明”填写 `http://127.0.0.1:8766/api/transit` 并应用；或者停止原预览后，在预览包目录执行：

```powershell
start-preview.cmd --feed http://127.0.0.1:8766/api/transit --no-open
```

再访问启动窗口地址并加上 `/?live=1&view=bus`。确认读取时间持续变化，失败和过期提示仍然有效。预览包不附 Python，也不会自动启动采集器。手机上的 `127.0.0.1` 指手机本身，不能访问电脑服务。

## 继续开发与部署

配套源码包的 `README.md` 提供安装、构建和验证命令，`TODO.md` 提供验收条件，`docs/DATA-INTERFACES.md` 提供已有和缺失接口。

Mac/Linux 成员可安装 Node.js 后，在预览包运行 `node preview-server.mjs`；附带的 `runtime/node.exe` 仅适用于 Windows。

静态部署使用 `site/` 内容作为 Web 根目录，不直接双击 `site/index.html`。公共部署的实时服务需另行实现同源 HTTPS 接口，不能使用每个访客的本机地址。保留页面地图署名及 `licenses/` 依赖许可证。
