# 珞珈畅行 · 团队 UI 预览

这是 MVP 前端 UI 审查包，供团队查看页面风格和交互。

## Windows 免安装打开

1. 将整个 ZIP 解压到一个普通文件夹，不能直接在压缩软件中启动。
2. 双击 `start-preview.cmd`，浏览器会自动打开预览页面。
3. 浏览期间保持启动窗口打开；关闭窗口或按 Ctrl+C 即可停止预览。

适用于 Windows 10/11、x64 系统。已附带 Node.js 运行时，不需要安装 Node.js，也不需要下载项目依赖。建议使用最新版 Chrome 或 Edge。

默认地址为 http://127.0.0.1:4173；端口被占用时会自动选择下一个可用端口，以启动窗口显示的地址为准。地址仅在运行预览的电脑上有效。

## 审查内容

- 配色、字体、信息密度和桌面布局。
- 校园地点搜索、起终点交换、收藏和三种出行方案切换。
- 地图缩放、图层、浅色底图与卫星影像。
- 校巴线路、站点、管制公告和本地出行问答。
- 手机尺寸下的布局，可通过浏览器设备预览查看。

`screenshots/` 包含桌面和手机截图，没有网络时也能查看。

## 数据与网络

地图底图与卫星影像需要联网，地图源为 Esri。若底图不可用，页面会提示，其他本地交互仍可使用。

校巴线路、站次、轨迹和车辆来自 `bus.whu.edu.cn`，默认使用随包采集快照；超过 30 秒显示过期。可在配套源码目录启动 `python scripts/transit/collector.py --serve`，并在页面“数据说明”填写 `http://127.0.0.1:8766/api/transit` 持续更新。预览包本身不含 Python 运行时，接入说明见源码 `docs/LIVE-BUS.md`。

校园地点、管制记录、步行/骑行规划和本地规则问答仍为演示数据，固定快照为 2026-10-10 09:30。校巴坐标系未经上游明确声明，按高德用法推断转换；5 号线时刻表存在来源冲突。页面不生成校巴抵达分钟数，不能作为实际导航依据。

## Mac / Linux 与继续开发

Mac 或 Linux 成员可在安装 Node.js 后，在本文件夹运行 `node preview-server.mjs`，浏览器将自动打开；`runtime/node.exe` 仅供 Windows 使用。

需要继续开发时使用配套源码包。源码包的 `README.md` 包含安装、启动与测试说明。

本包也可部署为静态站点：将 `site/` 文件夹内容放到静态 Web 服务的根目录即可。不要直接双击 `site/index.html`，页面的交互资源需要通过本地预览服务加载。
